## 3. 描述（≤4000）

推し箱是一个私密相册。自推的图、谷子的照片、不想被翻到的截图和文档——你想留着，却不想让它们出现在系统相册里，就把它们收进推し箱。

【只属于你】
• 不需要注册账号，没有广告，没有任何统计和追踪
• 内容只保存在你的设备上；开启 iCloud 同步时，也只保存在你自己的 iCloud 里，开发者无法访问
• 从照片图库导入后，可以一键从系统相册删除原图，照片只留在推し箱

【隐藏与上锁】
• 照片、相簿都可以单独隐藏，日常浏览时完全看不到
• 打开 App、查看隐藏内容时，可以要求面容 ID / 触控 ID 验证
• 离开 App 后，隐藏内容自动收起

【照片、视频、PDF 都能放】
• 支持照片、实况照片、动图、视频和 PDF
• 视频双击播放 / 暂停，拖动进度条快速定位
• PDF 像照片一样逐页翻看，可以放大细看

【顺手的整理】
• 用相簿分门别类，长按拖动自由排序
• 双指捏合切换每行张数，从一行一张到一行十五张
• 批量选择、加入相簿、隐藏、分享、删除
• iPad 上可以把照片直接拖到侧栏的相簿里

【沉浸浏览】
• 全屏查看，双指放大，左右滑动翻看
• 底部缩略图条快速跳转
• 支持从左到右、从上到下、连续长条三种查看方式

【iCloud 同步（可选）】
• 在你登录同一 Apple 账户的 iPhone 和 iPad 之间同步图库和相簿

## 5. App 隐私（App Store Connect › App 隐私）

- 「你或你的第三方合作伙伴是否从此 App 中收集数据？」→ **否，我们不从此 App 中收集数据**
- 结果页显示「未收集数据」。
- 依据：App 没有账号、没有网络请求（iCloud 同步走用户自己的 iCloud，Apple 不算开发者收集）、没有第三方 SDK。隐私清单 `AnimeAlbum/PrivacyInfo.xcprivacy` 已声明：不追踪、不收集，用到 UserDefaults（理由 CA92.1）。

## 7. 审核备注（App Review Information › Notes）

```
推し箱是一个本地私密相册，不需要登录，没有测试账号。

测试方法：
1. 第一次打开会显示功能介绍和《用户协议》《隐私政策》，勾选同意后进入。
2. 在「图库」右上角「…」中选择「从照片图库导入」或「从文件导入」添加照片、视频或 PDF。
   从照片图库导入完成后，App 会询问是否从系统相册删除原图；只有选择删除时才会请求照片图库权限
   （NSPhotoLibraryUsageDescription），且只删除刚导入成功的那些项目，系统还会再弹出删除确认。
3. 隐藏：长按照片选择「隐藏」；在右上角「…」的「显示」中切换「只显示隐藏的 / 全部显示」查看。
4. 面容 ID：在「设置 › 隐私与安全」中开启「打开 App 时需要面容 ID」或「查看隐藏内容时需要面容 ID」
   （NSFaceIDUsageDescription）。
5. iCloud 同步（可选）：「设置 › iCloud 同步」，数据存于用户自己的 CloudKit 私有数据库与 iCloud 云盘。

App 不收集任何数据，除 iCloud 同步外不发起网络请求。
```

联系信息：填你自己的姓名、电话、邮箱（只给审核人员看）。

## 10. 提交前检查清单

1. **CloudKit 生产环境**：在 [CloudKit Console](https://icloud.developer.apple.com/) 选择容器 `iCloud.dev.akisui.AnimeAlbum` → Schema → **Deploy Schema Changes 到 Production**。
   不做这一步，正式版的 iCloud 同步会失败。前提是开发版在真机上开过一次同步，让表结构自动建好（目前**还没在真机验证过 iCloud 同步**）。
2. **真机验证 iCloud 同步**：两台设备都打开同步，确认图库、相簿、隐藏标记能同步过去。
3. **归档**：Xcode › Product › Archive（Release 配置）→ Distribute App → App Store Connect → Upload。
   Xcode 会按发布描述文件自动把推送和 iCloud 环境设为生产。
4. **TestFlight**：上传后先在 TestFlight 装到手机上过一遍（尤其是首次启动、面容 ID、iCloud 同步）。
5. **App Store Connect**：新建 App（名称、主要语言、Bundle ID、SKU）→ 按上面填资料、上传截图 → 选择构建版本 → 提交审核。
6. **加密出口合规**：`Config/Info.plist` 已写 `ITSAppUsesNonExemptEncryption = NO`，上传后不会再问。
