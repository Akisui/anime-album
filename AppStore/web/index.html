推し箱 Oshibako

技术支持

推し箱是一款私密相册：把不想放进系统相册的照片、视频和 PDF 收在这里，可以隐藏、可以用面容 ID 上锁，所有内容只保存在你的设备和你自己的 iCloud 中。

常见问题

换手机后照片还在吗？

在「设置 › iCloud 同步」中打开同步后，内容会保存在你本人的 iCloud 里，新设备登录同一 Apple 账户并打开同步即可。未开启同步时，内容只在本机，请在换机前用 iCloud 同步或系统备份迁移。

隐藏的照片在哪里看？

在图库、相簿列表或相簿里点右上角「…」，在「显示」中选择「只显示隐藏的」或「全部显示」。如开启了「查看隐藏内容时验证」，需要先通过面容 ID / 触控 ID。

导入后系统相册里还有原图？

从照片图库导入完成后会询问是否从系统相册删除原图；删除的照片会先进入系统「照片」的「最近删除」，30 天后彻底删除，也可以在那里手动立即删除。

面容 ID 识别不了怎么办？

面容 ID / 触控 ID 不可用或连续失败时，可以改用设备密码解锁。
